## Pending protocol decisions and implementation gates

- **BC06 custody:** before retrying a pending/unknown custody effect, the application must lookup by stable intent ID and verify artifact ID, digest, session and source revision. An unavailable lookup leaves the intent pending/unknown. If the identified artifact digest conflicts, raise a typed integrity/security incident and do not overwrite it. An artifact reported by a future BC06 inventory but lacking a matching active BC14 intent is an orphan candidate: record an operator-visible reconciliation finding, request BC06 quarantine/retention through its public contract, and never delete bytes from BC14. BC14 cannot discover unreported artifacts without a BC06 inventory API. Retention duration remains a policy proposal for owners/legal review; no duration is selected here.
- **Outbox:** use a short PostgreSQL claim transaction with `FOR UPDATE SKIP LOCKED`, lease expiry and unique claim token; commit before calling BC15. A separate conditional completion transaction must reject stale tokens. Persist attempt count, bounded exponential backoff, failure classification and dead-letter/needs-attention state. Delivery is at-least-once; the receiver double must deduplicate the stable event ID. `sent`, receiver `acknowledged` and downstream playbook approval are distinct facts. This protocol has not yet been implemented or tested.
- **Required before PR:** durable lookup/reconciliation and tested orphan-candidate policy; application-integrated relay with concurrent lease/reclaim/fencing/backoff tests against PostgreSQL and process restart; broader replay authorization matrix; subsequent full local and remote CI evidence plus human ADR review.

Guarantee categories: **domain tests** prove domain transitions/reference/budget rules; **PostgreSQL/process tests** prove tested database transactions, CAS and child-process crash scenarios; **doubles** simulate BC06/BC15 idempotent effects only; **out of S1** are production egress, real context services, distributed exactly-once, and global artifact inventory. No report may upgrade a double to a production guarantee.
